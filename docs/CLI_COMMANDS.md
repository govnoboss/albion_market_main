# ⌨️ Справочник консольных команд (CLI Guide)

Этот документ содержит список команд и инструментов для управления ботом. Команды вводятся в терминале (PowerShell или CMD) в корневой папке проекта.

---

## 🚀 Основные команды (Для пользователя)

### Запуск бота
```powershell
python src/main.py
```
**Что делает:** Запускает графический интерфейс бота. Самый частый способ использования.

### Упаковка в программу (Build)
```powershell
.\build.bat
```
**Что делает:** Превращает исходный код в один файл `GBot.exe`, который можно запускать без Python. Все файлы появятся в папке `dist\GBot.dist`.

### Создание архива для пересылки
```powershell
.\package.bat
```
**Что делает:** Берёт собранный `.exe`, добавляет в него Tesseract и инструкции, после чего упаковывает всё в ZIP-архив. Готовый файл `GBot.zip` можно отправлять другим людям.

## 🔑 Управление ключами и данными

### Создание новых ключей
`python tools/generate_keys.py`
**Зачем это:** Генерирует новую пару RSA ключей. **Внимание:** если создать новые ключи, старые лицензии перестанут работать, пока не обновите `public.pem` в боте.

### Обновление базы данных (Локально)
`python tools/migrate_db.py`
**Зачем это:** Если в новой версии сервера добавились новые поля, этот скрипт обновит структуру локальной базы данных перед деплоем.

### Миграция БД (IP-поля)
`python tools/migrate_db_ip.py`
**Зачем это:** Добавляет поля IP-адресов в базу данных сервера. Запускается один раз при обновлении до версии с поддержкой IP-трекинга.

## 📦 Релиз и деплой

### Release Manager (GUI)
```powershell
python tools/release_manager.py
```
**Зачем это:** GUI-инструмент для полного цикла релиза. Обновляет `CURRENT_VERSION` в `version.py`, запускает `build.bat`, упаковывает в ZIP через `package.bat`, публикует GitHub Release с тегом. Это основной инструмент для выпуска обновлений.

### Деплой сервера на Fly.io
```powershell
.\tools\deploy_server.ps1
```
**Зачем это:** Автоматический деплой лицензионного сервера на Fly.io. Проверяет ключи и обновляет приложение в облаке.

### Конвертация иконки (PNG → ICO)
```powershell
python tools/convert_icon.py
```
**Зачем это:** Конвертирует `assets/icon.png` в `assets/icon.ico` для Windows-сборки. Вызывается автоматически из `build.bat`.

## 🧪 Тестирование

### Автотесты
`python tests/run_test.py`
**Зачем это:** Запускает автоматическую проверку всех функций бота (логика расчета прибыли, парсинг текста и т.д.) без открытия самого окна игры. Идеально для быстрой проверки после изменений в коде.

### OCR Тестер (GUI)
```powershell
python tools/ocr_tester.py
```
**Зачем это:** GUI-инструмент для тестирования и настройки OCR фильтров. Позволяет сравнивать различные конфигурации (Scale, Threshold, Inversion), смотреть превью обработанных изображений и сохранять/загружать пресеты для оптимальной точности распознавания.
