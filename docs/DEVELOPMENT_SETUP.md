# 🛠 Руководство по развертыванию (Development Setup)

Это руководство поможет вам настроить рабочее окружение на новом компьютере для разработки или запуска бота из исходного кода.

---

## 1. Предварительные требования
*   **Python 3.13** (или 3.11+). [Скачать Python](https://www.python.org/downloads/)
    *   *Важно:* При установке поставьте галочку **"Add Python to PATH"**.
*   **Git** для Windows. [Скачать Git](https://git-scm.com/download/win)
*   **Tesseract OCR** (уже включен в проект в папке `assets/tesseract`).

---

## 2. Первоначальная настройка

### Шаг 1: Получение кода
Если вы на новом компьютере, склонируйте репозиторий:
```powershell
git clone https://github.com/govnoboss/albion_market_main.git
cd albion_market_main
```

### Шаг 2: Создание виртуальной среды (VENV)
Виртуальная среда нужна, чтобы библиотеки проекта не конфликтовали с системными. Она **не переносится** через Git и создается на каждом ПК заново.

В корне проекта выполните:
```powershell
# Создание среды
python -m venv .venv
```

### Шаг 3: Активация среды
Теперь нужно сказать терминалу использовать именно эту среду.
*   **В PowerShell:**
    ```powershell
    .\.venv\Scripts\Activate
    ```
    *Если PowerShell выдает ошибку прав, запустите его от админа и введите: `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`*

### Шаг 4: Установка зависимостей
```powershell
pip install -r requirements.txt
```

---

## 3. Работа с проектом

### Как запускать
Всегда проверяйте, что среда активирована (в начале строки терминала должно быть `(.venv)`).
```powershell
python src/main.py
```

### Синхронизация между ПК
1.  **На основном ПК** (после правок):
    ```powershell
    git add .
    git commit -m "Описание изменений"
    git push
    ```
2.  **На новом ПК** (чтобы получить правки):
    ```powershell
    git pull
    ```
    *Если были добавлены новые библиотеки, не забудьте снова запустить `pip install -r requirements.txt`.*

---

## 4. Первый запуск и конфиги
Файлы конфигурации (`config/`) и цен (`data/`) **игнорируются** Git-ом (прописаны в `.gitignore`).

При первом запуске на новом ПК:
1.  Бот создаст папку `config` и файл `coordinates.json` с дефолтными значениями.
2.  Вам нужно будет заново провести калибровку координат или **вручную** скопировать папку `config` со старого ПК.
3.  Для активации лицензии потребуется ввести ваш ключ (он сохранится локально).

---

## 5. Компиляция в .exe (Nuitka)
Если вам нужно собрать бота для пользователей:
1. Установите Nuitka: `pip install nuitka`
2. Запустите скрипт сборки: `.\build.bat`
    *   *Примечание:* Скрипт автоматически запустит **Unit-тесты**. Если они не пройдут, сборка будет отменена.
3. Соберите архив для отправки: `.\package.bat`

### Release Manager (GUI)
Для полного цикла релиза (обновление версии → сборка → упаковка → публикация на GitHub):
```powershell
python tools/release_manager.py
```
Этот инструмент автоматически обновляет `CURRENT_VERSION` в `src/core/version.py`, собирает `.exe`, упаковывает ZIP и публикует GitHub Release.
